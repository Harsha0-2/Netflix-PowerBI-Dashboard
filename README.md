Netflix Data Visualization Dashboard (Power BI)

1.Project Overview
This project visualizes Netflix content using **Power BI**.  
It provides insights on movies vs TV shows, top genres, country distribution, top directors, and release trends over the years.  
The data was cleaned and prepared using **Excel**, and the dashboard was built for interactive analysis.

---

2.Key Insights from Dashboard
- Total Titles: 6173
- Movies: 5943
- TV Shows: 230
- 'USA' & 'India' contribute to most of the content.
- Highest content addition seen around '2018–2020' period.
- 'International Movies & Dramas' are the most popular genres.
- Top directors include 'Cathy Garcia, Youssef Chahine, Martin Scorsese', etc.
